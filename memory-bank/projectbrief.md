# Project Brief

## Project Goal
Create a web-based prototype to simulate the onboarding flow for an autonomous vehicle (AeroDrive), specifically designed to improve user trust in the system.

## Core Requirements
- Experience Tuning: Calibrating the vehicle's autonomous behavior (speed, braking, g-forces) to match the individual driver's comfort level.
- Driver Identification & Customization: Automatically recognizing the driver and instantly loading their specific system preferences and profiles.
- Interactive Tutorial: Gamifying and shortening the tutorial to make it immersive, ensuring users can focus and understand safety features (like take-overs) quickly.
- Visual Aesthetic: Needs to look like a modern, premium car dashboard.

## Key Directives
- **Build Trust**: The UI must feel responsive, safe, and highly personalized.
- **Stationary Context**: The onboarding flow is assumed to take place while the vehicle is parked (e.g., in a garage or driveway) before driving commences.
